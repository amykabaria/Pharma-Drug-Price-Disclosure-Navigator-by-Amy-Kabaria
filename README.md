# Pharma-Drug-Price-Disclosure-Navigator-by-Amy-Kabaria
This 2019 proof-of-concept I created shows how an interactive interface can present complex drug pricing transparency laws and decisions for pharmaceutical manufacturers. While based on statute, this proof-of-concept does not constitute legal advice. The 2019 information it presents may be outdated, and using this tool does not establish an attorney-client relationship.

As more context on the value of this early interactive interface, state pharmaceutical price-transparency laws have since expanded significantly in both number and scope. Following early adopters like Oregon and California, at least 20 states have adopted drug-price reporting requirements since. Newer laws require reporting from across the pharmaceutical supply chain (from health plans, wholesalers, PBMs, and more in addition to manufacturers).
